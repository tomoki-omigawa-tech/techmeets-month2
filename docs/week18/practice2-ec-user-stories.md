# 練習課題2：ECサイトのユーザーストーリー

練習課題1の「ベーカリー麦の穂」オンラインショップ（店頭受け取り予約＋配送の通販）を題材にする。

## 利用者
| ロール | 説明 |
|---|---|
| ゲスト | 会員登録していない訪問者 |
| 会員 | 会員登録済みの購入者 |
| 店舗スタッフ | 商品と注文を管理する店長・スタッフ |

## 主要ストーリーの受け入れ基準
**US-06 受け取り日時の選択**
- 選べるのは翌日〜14日後の営業日のみ（定休日は選べない）
- 受け取り時間は営業時間内の30分単位で選べる
- 予約上限に達した商品がある日は選べない

**US-07 クレジットカード決済**
- 決済に成功した場合のみ注文が確定する
- 決済に失敗した場合はエラーを表示し、カートの内容は残る
- カード情報はサイトのDBに保存しない（決済サービスで処理する）

## INVEST原則によるチェック（US-06の例）
| 原則 | 判定 | 理由 |
|---|---|---|
| Independent | ○ | 配送の機能がなくても単独で作れる |
| Negotiable | ○ | 時間の単位（30分か1時間か）は後で調整できる |
| Valuable | ○ | 焼きたてを都合のよい時間に受け取れる |
| Estimable | ○ | 日付・時間の選択と上限チェックなので見積もれる |
| Small | ○ | 1スプリントで完了できる |
| Testable | ○ | 受け入れ基準が明確 |

## 大きすぎるストーリーの分割例
「会員として、商品を購入したい」は大きすぎて Small と Estimable を満たさないため、次のように分割した。

- カートに入れる（US-04）
- 受け取り方法を選ぶ（US-05）
- 受け取り日時を選ぶ（US-06）
- 支払う（US-07）
- 確認メールを受け取る（US-08）
